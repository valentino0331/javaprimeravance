Descripción del Proyecto

El "Sistema de Rendición de Cuentas" es una aplicación web moderna desarrollada en Angular 20 diseñada para gestionar de manera eficiente los viáticos, papeletas de comisión y rendición de gastos en instituciones públicas.

Este proyecto fue desarrollado como parte de un trabajo grupal para estudiantes de Ingeniería de Sistemas, implementando conceptos modernos de desarrollo web, arquitectura de componentes y mejores prácticas en programación.

La aplicación permite un flujo completo de CRUD (Crear, Leer, Actualizar, Eliminar) para gestionar todos los datos relacionados con comisiones y gastos de los colaboradores.

Objetivos del Proyecto

Gestión de Datos

Proporcionar una plataforma centralizada para registrar y gestionar viáticos y comisiones.

Consultas Eficientes

Permitir búsquedas y filtros avanzados para encontrar información rápidamente.

Transparencia

Mantener un registro claro y auditable de todos los gastos y comisiones.

Aprendizaje

Demostrar competencias en desarrollo web moderno con Angular y tecnologías asociadas.

Cómo Ejecutar el Proyecto

Pasos de Instalación: 
npm install
npm install bootstrap
npm install bootstrap-icons
npm install json-server
Ejecutar la Aplicación:

Abre dos terminales:

Terminal 1 - JSON Server:

npm run json-server

Terminal 2 - Angular App:

ng serve --open

La aplicación se abrirá en http://localhost:4200
